## Day 8 – Exit Ticket

**What did I build?**

I built a responsive ten-page website for a software development company called CodeNest using HTML, CSS, Bootstrap, and JavaScript.

**What did I learn?**

I learned how to create a complete multi-page website using Bootstrap, maintain consistent styling, and use interactive components such as accordions, modals, dropdowns, and offcanvas navigation.

**What challenges did I face?**

I faced some challenges with navigation links, image sizes, responsive layouts, and dynamic page content. I solved these issues by reviewing my code and testing the website.

**What would I improve in the future?**

I would connect the contact form to a backend, add a database, and improve the website's performance and accessibility.
