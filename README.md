# CodeNest – Bootstrap Website

## Project Overview

CodeNest is a responsive multi-page website for a fictional software development company. The website presents the company's services, software products, pricing plans, client testimonials, articles, and contact information.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5.3.3
- Bootstrap Icons
- JavaScript
- Git and GitHub

## Website Pages

| Page | Description |
|---|---|
| Home | Company introduction and main sections |
| About Us | Company story, mission, vision, and values |
| Services | Software development and technology services |
| Products | Available software products |
| Product Details | Dynamic product information |
| Pricing | Available subscription plans |
| Testimonials | Sample client feedback |
| FAQ | Frequently asked questions |
| Blog | Technology articles |
| Contact Us | Contact form with validation |

## Main Features

- Responsive design for desktop, tablet, and mobile.
- Consistent navigation and footer across all pages.
- Bootstrap grid system and reusable components.
- Offcanvas mobile navigation.
- Dropdown navigation menu.
- Interactive FAQ accordion.
- Bootstrap modals for blog articles.
- Dynamic product details using URL parameters.
- Automatic service and pricing plan selection.
- Contact form validation.
- Custom CSS styling and hover effects.

## How to Run

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using Live Server.
4. Navigate through the website.
